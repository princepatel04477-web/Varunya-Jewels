# Varunyaa

Luxury gold jewelry storefront built with Next.js 15, TypeScript, Tailwind v4, Motion and an intentionally restrained editorial system.

## Photography

Product masters must be exported as Display P3 AVIF with an sRGB fallback. Preserve ICC profiles throughout the asset pipeline; accurate gold colour is a product requirement. Next Image qualities are restricted to 85 and 95.

## Development

```bash
npm install
npm run dev
```
